# ภูเก็ตกราฟ – Interactive Web App (Discrete Mathematics)

เว็บแอปแบบโต้ตอบ 4 หน้า ธีมท่องเที่ยวทะเลภูเก็ต ประยุกต์คณิตศาสตร์ดิสครีต

## หัวข้อคณิตศาสตร์ดิสครีต
- **ทฤษฎีกราฟ**: กราฟถ่วงน้ำหนัก, ดีกรี, Handshaking Lemma, BFS, DFS, Dijkstra
- **ต้นไม้ (Tree)**: ต้นไม้จากการค้นหา BFS/DFS และต้นไม้ค้ำจุนน้อยสุด (Kruskal + Union-Find)

## 4 หน้า
1. แผนที่กราฟ
2. สำรวจ BFS / DFS
3. เส้นทางสั้นสุด (Dijkstra)
4. ต้นไม้ค้ำจุนน้อยสุด (MST)

## โครงสร้างไฟล์
- `index.html` โครงหน้าเว็บ
- `style.css` การตกแต่ง
- `script.js` ข้อมูลกราฟและอัลกอริทึม

## วิธีรันบนเครื่อง
เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย

## วิธีเผยแพร่บน GitHub Pages
1. สร้าง repository ใหม่บน GitHub แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้
2. ไปที่ Settings > Pages
3. ที่ Source เลือก Deploy from a branch, Branch เลือก `main` และโฟลเดอร์ `/ (root)` แล้วกด Save
4. รอสักครู่ เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repo>/`

หมายเหตุ: ระยะทางระหว่างสถานที่เป็นค่าประมาณเพื่อการเรียนรู้
